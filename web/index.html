How it works

  1. Split narration into sentence-level scenes.
  2. Route meaning to a footage query using phrase-level concepts.
  3. Choose unique footage or use an explicit procedural fallback.
  4. Normalize clips to each aspect ratio, synchronize the narration, and generate captions.
  5. Export timeline.json and manifest.json with rights metadata and warnings.

Prototype note: relevance is not independently scored yet. Review every clip and verify licence terms before commercial publishing.
